# Estimator Framework

## Goal

A professional WordPress construction estimator that allows homeowners to estimate remodeling costs and request a quote, while allowing administrators to manage all pricing from the WordPress dashboard.

## 🔨 Items

Each Item belongs to one Category.

Each Item contains:

- Name
- Description
- Minimum Price
- Maximum Price
- Display Order
- Active

Each Category contains:

- Name
- Selection Type
    - Single Choice
    - Multiple Choice
